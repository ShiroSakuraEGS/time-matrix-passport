# 🌌 賽博時空簽證護照 (Cyber Time Passport)

> **一款結合賽博龐克 (Cyberpunk)、故障藝術 (Glitchcore) 與未來引渡證件美學的 Chrome 網頁擴充套件時間管理神器！**

---

## ✨ 核心特色與功能亮點

1. 🛂 **未來賽博護照外殼（Cyberpunk Passport UI）**
   - 擬真量子防偽晶片（Holo-Chip）、賽博生體辨識條碼、動態螢幕掃描線（Scanlines）與霓虹光效。
   - 支援**網頁懸浮可拖曳小工具（In-Page Floating Widget）**：在任何網頁右下角隨時常駐，可最小化為賽博印章呼吸光徽章，點擊即可展開護照。
   - 支援**瀏覽器右上角彈出式視窗（Extension Popup）**與**獨立分頁展示中心（`preview.html`）**。

2. ⏱️ **賽博印章造型時鐘（Temporal Clearance Seal）**
   - 雙重金屬刻痕外環與 60 秒高速旋轉雷射刻度環，刻印有「★ TEMPORAL CLEARANCE SEAL ★ CYBERSPACE TIME MATRIX ★」。
   - 中心大字體數位碼表（`00:00:00`），具備綠色「計時中」、黃色「暫停中」與待命光環。
   - 擬真蓋印衝擊反饋（Stamp Thump Animation）與 Web Audio 原生合成的機械蓋印重音與電子故障音效。

3. 📊 **Google 試算表（Google Sheets）無縫雲端串接**
   - 免除繁瑣的 GCP OAuth 2.0 審查認證，採用超穩定的 **Google Apps Script Web App Webhook** 架構。
   - 內建**「一鍵複製 Apps Script 雲端腳本」**與**「連線測試（PING SYNC）」**按鈕。
   - 自動在 Google 試算表建立極具科技感的深色表頭（時間戳記、項目代號、項目名稱、開始時間、結束時間、時長、備註說明、簽證ID）。
   - 具備離線防丟快取，即使無網路或未設定試算表，亦會完整備份於本地護照資料庫。

4. 🏷️ **通關項目彈性管理（Projects Management：支援增加與刪除）**
   - 支援快速下拉切換項目。
   - **新增通關項目**：可自訂項目名稱、賽博代號（如 `DEV-01`、`IRON-26`、`DESIGN-X`）與專屬霓虹識別標籤色。
   - **刪除通關項目**：
     - 在項目選單旁提供【🗑️ 刪除】快捷鈕，可移除選取項目及其印章。
     - 亦可在【時空簽證詳細說明檢視器】中一鍵刪除該項目，或點擊個別日誌右側的 `&times;` 單獨刪除指定簽證紀錄。

5. ⚡ **選擇項目 + 印章時鐘計時、暫停與完成蓋印**
   - 點擊【蓋印開始】，印章時鐘啟動旋轉並開始計時。
   - 支援【暫停】與【繼續】操作。
   - 點擊【完成簽證】，印章大力蓋下並彈出備註輸入框，填入工作摘要後秒級同步至 Google 試算表！

6. 📜 **護照簽證分頁（Passport Visa Pages & 總時長印章）**
   - 多頁式翻頁護照（`PAGE 01 / 02`），以復古兼具霓虹印泥質感在護照紙上呈現各項目的「實體簽證印章」。
   - 印章即時動態統計**「累積通關總時長（TOTAL CLEARANCE TIME）」**與蓋印次數。
   - **點擊任何印章卡片**：即可彈出「時空簽證詳細說明檢視器」，逐筆瀏覽該項目每一次計時的起訖時間、單次時長與備註紀錄，並可一鍵直達 Google 試算表！

7. 📁 **支援 CSV 匯出與 CSV 匯入（相容 Excel 與 Google Sheets）**
   - **匯出 CSV**：內建 UTF-8 BOM 標記，在 Windows Excel 中開啟絕不亂碼，標準包含 `蓋印時間, 項目代號, 項目名稱, 開始時間, 結束時間, 經過秒數, 累積時長, 簽證備註, 簽證識別碼`。
   - **匯入 CSV**：自動解析試算表檔案，若遇到未登錄之項目代號/名稱會**自動建立該通關項目**並回填完整通關日誌。
   - 同步保留完整系統層級之 JSON 備份與還原功能。

## 🚀 快速安裝與使用教學

### 方法一：載入至 Chrome 瀏覽器使用（擴充套件模式）

1. 開啟 Chrome 瀏覽器，在網址列輸入：
   ```text
   chrome://extensions/
   ```
2. 開啟右上角的**「開發人員模式 (Developer mode)」**開關。
3. 點選左上角的**「載入未封裝項目 (Load unpacked)」**按鈕。
4. 選取本專案目錄：
   ```text
   C:\Users\Anubis.Chan\Downloads\鐵人賽\實驗場所\time整理
   ```
5. 安裝完成！您會在瀏覽器工具列看到賽博時空印章圖示，且在瀏覽任何網頁時，右下角皆會浮現專屬懸浮徽章！

---

若您想立即體驗完整介面與功能，直接雙擊或以瀏覽器開啟目錄下的：

## 📈 Google 試算表 3 步驟串接指引

1. **新建試算表**：
   - 開啟 [Google 試算表 (Google Sheets)](https://sheets.new) 建立一份空白試算表。
2. **貼上腳本**：
   - 點擊上方選單【擴充功能】➔【Apps Script】。
   - 清空裡面的內容，複製本專案內的 `google-apps-script.js` 完整代碼（或在套件設定中點擊【一鍵複製 Apps Script 腳本】）並貼上儲存。
3. **部署為網頁應用程式**：
   - 點選右上角【部署】➔【新增部署】。
   - 點左側齒輪選【網頁應用程式】（Web App）。
   - **重要設定**：
     - 執行身分：**我 (您的 Google 帳號)**
     - 誰可以存取：**任何人 (Anyone)**（請務必選 Anyone，套件才能將資料傳入試算表）
   - 點擊【部署】，複製產生的「網頁應用程式網址（Web App URL）」。
4. **填入護照套件**：
   - 回到賽博護照的【03 // 雲端設定】分頁，將網址貼入【Google Apps Script Web App 網址】並點擊【儲存設定】。
   - 點擊【測試連線 (PING)】，看到成功訊息即代表串接完畢！
